# Проект автоматизации тестирования сайта Stellar Burgers

## 📌 Описание

Проект написан на Python с использованием Selenium и Pytest. Покрывает основные пользовательские сценарии на сайте [Stellar Burgers](https://stellarburgers.nomoreparties.site):

- Регистрация нового пользователя
- Вход с существующим аккаунтом
- Переходы между страницами (личный кабинет, конструктор, логотип)
- Выход из аккаунта
- Навигация по разделам конструктора (Булки, Соусы, Начинки)
